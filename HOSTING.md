# Host Calibrate

Static site. No server, no database. Checks stay in the browser.

## See it now
Open `app.html` in Chrome or Safari. That file is the whole app.

## Host it yourself (free)

### GitHub Pages
1. Repo: this project
2. Settings → Pages → Deploy from branch `main` → `/ (root)`
3. Site: `https://neerumsr.github.io/calibrate-diy/`

### Vercel
1. vercel.com → Add New → Import GitHub repo `calibrate-diy`
2. Framework: Other.
3. Deploy. Attach your own domain later.

### Netlify
Drag the folder onto https://app.netlify.com/drop

## Grok Build / grok.me
Publish-to-grok.me only works inside Grok Build mode on grok.com (Publish). This repo is the source you can paste or import.
